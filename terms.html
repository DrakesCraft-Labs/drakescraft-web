Términos de compra

Compras para DrakesCraft.

Estas condiciones describen el flujo de compra. Tebex procesa el pago y sus términos aplican además de los de DrakesCraft.

Entrega

Los productos se asignan al nick proporcionado durante el checkout. El comprador debe escribirlo con exactitud. Las compras de Bedrock deben incluir el punto inicial cuando corresponda.

Pases y duración

Los pases temporales se venden como compras manuales por su duración indicada. No se renuevan automáticamente desde DrakesCraft; una renovación exige una nueva compra hecha por el jugador.

Reembolsos y errores

Una entrega completada y utilizada no se revierte por cambio de opinión. Si hay una entrega incorrecta o fallida, repórtala por Discord con el ID de Tebex para revisar el registro antes de cualquier ajuste.

Reglas del servidor

Comprar un beneficio no elimina las reglas de juego, moderación o seguridad. Beneficios obtenidos mediante fraude, suplantación o abuso pueden ser revocados mientras se investiga el caso.

Privacidad

DrakesCraft usa el nick, el producto y el identificador de transacción para procesar soporte. Los datos de pago se manejan en Tebex y no deben enviarse por Discord.
